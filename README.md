# Commercial Utility Bill & Tariff Recovery

Full React, Express, PostgreSQL, and OpenRouter application with 15 domain capabilities, 60 custom fields, three scenario-fill buttons per capability, and at least 15 seeded PostgreSQL records per feature.

Run `./start.sh`, then open <http://127.0.0.1:4541>. The API runs on `5541`. The login provides one-click credentials for administrator, operator, and reviewer roles.
